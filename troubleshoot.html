No internet connection. What should I check?

Follow the network ladder from the bottom up: connection, IP address, router, external connectivity, DNS. The first step that fails points to the likely cause.

    Run the diagnostics scripts yourself

    Two read-only Node.js scripts automate these checks. Run them only on a computer you are authorised to troubleshoot (not on a managed or school machine without permission):

    node tools/network-doctor.js   node tools/pc-health.js

    They never change settings, install updates, change firewall rules or scan networks. Browsers cannot run them: this page cannot inspect your computer.
